# WebShooter

WebShooter is a simple Minecraft plugin that adds Spider-Man-like abilities to players, including web-slinging and wall-crawling. This plugin is designed to enhance the gameplay experience by providing unique movement mechanics inspired by the Spider-Man comic and movies.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server.

## Use

1. Join the Minecraft server where the plugin is installed.
2. Use the command `/spiderman` to toggle Spider-Man abilities.
3. While sneaking, you can web-sling by moving in the direction you want to go.
4. When near a wall, you can wall-crawl by moving towards the wall.
